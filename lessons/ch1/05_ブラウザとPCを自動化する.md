# ブラウザとPCを自動化する

Claudeが皆さんのブラウザに入り、いま見ているページを一緒に見ながら働く回です。前半は「Claude in Chrome」でページの要約からタブ横断リサーチまで、後半は「Cowork」でPC全体のファイル整理や資料の初稿づくりを任せ、"頼む"から"任せる"へ進みます。

---

## STEP1　ブラウザで動くAIを体験する（🎬 体験する）

**ゴール：** 開いているページをそのままClaudeに読ませる（目安25分）

**🎙️ 導入トーク**
「ここまでのClaudeは、こちらが資料を渡すのを待っていました。今日からは違います。Claudeが皆さんのブラウザに入って、いま見ているページを一緒に見ながら働きます。まずはインストールして、1ページ読ませてみましょう。」

1. Chrome ウェブストアで「Claude in Chrome」を検索し、拡張機能を追加する
2. Claudeアカウントでログインし、ブラウザ右上のアイコンから開く
3. 仕事に関係するWebページ（業界ニュース・行政の案内・製品ページなど）を開く
4. 「このページを3行で要約して」と頼む
5. 続けて「このページの内容で、うちの業務に関係しそうな点は？」と聞いてみる

**✨ 種明かし**
「コピペなしで、ページの内容がそのまま通じましたね。これが『Claude in Chrome』です。ページの要約・翻訳・質問はもちろん、この後やるように、複数のタブをまたいだ調べものまでこなします。」

---

## STEP2　Chromeでできることを整理する（📖 学ぶ）

**ゴール：** Claude in Chrome の守備範囲を整理する（目安30分）

**🎙️ 導入トーク**
「Claude in Chrome にできることを整理します。『読む』だけではなく『書く』『比べる』までできるのがポイントです。」

| できること | 頼み方の例 | 効く場面 |
| --- | --- | --- |
| ① 要約・翻訳・Q&A | 「要約して」「日本語にして」「この規約で注意すべき点は？」 | 長いページ・英語ページ・規約の読み込み |
| ② フォーム入力の下書き | 「この問い合わせフォームに、〇〇の内容で下書きを入れて」 | 申請・問い合わせ・アンケート回答 |
| ③ メールの下書き | 「このスレッドへの返信案を、丁寧なトーンで」 | Webメールでの日々の返信 |
| ④ タブ横断リサーチ | 「開いている3つのタブの内容を比較表にして」 | 比較検討・相見積り・市場調査 |

**💡 安全に使うためのルール**
ブラウザで動くAIには必ず確認の習慣を。**送信ボタンは自分で押す**（下書きまで任せて、送るのは人間）、**ログイン情報やカード番号は任せない**、**会社の機密ページでは使う前に社内ルールを確認**。この3つを守れば安心して使えます。

**✨ 種明かし**
「②と③が『代行』の入り口です。ここで大事な考え方——Claudeは下書きまで、最後の送信は自分。この線引きさえ守れば、ブラウザ仕事の面倒な部分だけを安全に手放せます。」

## STEP3　リサーチを実践する（✋ 実践する）

**ゴール：** タブ横断リサーチ→ドキュメント化を一気通貫でやる（目安35分）

**🎙️ 導入トーク**
「では実践です。お題は『比較して、まとめて、報告できる形にする』。仕入先の比較でも、ツール選定でも、競合調査でも、自分の業務の調べものに置き換えてやってみましょう。」

1. 比較したい対象のページを3つ、別々のタブで開く（製品・サービス・料金ページなど）
2. Claude in Chrome に「開いているタブの内容を、料金・特徴・注意点の比較表にして」と頼む
3. 「この比較から、うちの条件（予算〇〇・重視するのは〇〇）に合うのはどれか、理由つきで」と判断材料をもらう
4. 「この内容を、上司に共有する検討メモの形にまとめて」とドキュメント化する
5. できたメモをコピーして、Docs や Word に貼って仕上げる

**✨ 種明かし**
「タブを行き来してメモ帳に貼り付けて…という調べものの手間が、まるごと消えました。これが『リサーチ → ドキュメントのワンフロー』です。ただし覚えておいてください——Claudeが読んだのは"開いているページ"だけ。載っていないことは分かりませんし、ページの情報が古いこともあります。最後の裏取りは人間の仕事です。」

---

## STEP4　Cowork入門（📖 学ぶ）

**ゴール：** Cowork＝自律的に動くClaudeの仕組みを理解する（目安30分）

**🎙️ 導入トーク**
「後半は、ブラウザを飛び出してPC全体の話です。Claude Desktopアプリには『Cowork』というタブがあります。普通のチャットと何が違うのか。一言でいうと——チャットは"質問に答える人"、Coworkは"仕事を最後までやる人"です。」

|  | Chat（チャット） | Cowork |
| --- | --- | --- |
| 動き方 | 1回聞かれて1回答える | 計画を立て、実行し、結果を報告するまで自分で回す |
| 触れる範囲 | 会話と渡された資料 | 許可したフォルダの中のファイルを直接読み書き |
| 向いている仕事 | 相談・文章づくり・分析 | ファイル整理・資料の組み立て・繰り返し作業 |

1. Claude Desktop をインストールし、起動して「Cowork」タブに切り替える
2. 作業させたいフォルダへのアクセスを許可する（まずは練習用フォルダを1つ作るのがおすすめ）
3. 「このフォルダに何があるか、一覧にして教えて」と最初の仕事を頼んでみる

**💡 セキュリティの考え方**
Coworkが触れるのは**自分が許可したフォルダだけ**です。最初はデスクトップ全体ではなく、練習用フォルダから始めましょう。削除など取り返しのつかない操作は、実行前に必ず内容を確認する習慣を。「任せる範囲を自分で決められる」のがCoworkの安全設計です。

**✨ 種明かし**
「Coworkが自律的に動けるのは、**計画 → 実行 → 報告**のループを自分で回しているからです。頼まれた仕事をステップに分解し、1つずつ実行して、途中で問題があれば方針を変え、終わったら何をしたか報告する。新人に仕事を任せるときの流れと同じですね。だから頼み方も『作業の指示』ではなく『仕事のゴール』を伝えるのがコツです。」

## STEP5　PC作業を自動化する（✋ 実践する）

**ゴール：** ファイル整理と資料の初稿づくりを任せる（目安45分）

**🎙️ 導入トーク**
「Coworkに実際の仕事を2つ任せます。1つ目は誰もが見て見ぬふりをしている『フォルダの整理』。2つ目は『散らばったメモから資料の初稿を作る』です。」

1. **実践①：**練習用フォルダに、雑多なファイルを10個ほどコピーして入れる
2. 「このフォルダのファイルを種類ごとにサブフォルダへ整理して、ファイル名も『日付_内容』の形に統一して。実行前に計画を見せて」と頼む
3. 提示された計画を確認してから実行してもらい、結果の報告を読む
4. **実践②：**会議メモ・箇条書き・参考資料など、バラバラの素材を同じフォルダに入れる
5. 「この素材をもとに、〇〇の企画書の初稿をWordで作って。構成は背景・提案・スケジュール・費用」と頼み、初稿を受け取る

**💡 さらに横着する3つの機能（紹介）**
**スケジュール実行：**「/schedule」で「毎週金曜に週報の下書きを作る」のような定期タスクを設定できます。**グローバル指示・フォルダ指示：**「報告書はいつもこの形式で」のようなマイルールを覚えさせれば、毎回言わなくて済みます。**Chrome連携：**「Webで調べて、その結果をフォルダの資料に反映」のようなブラウザ込みの複合タスクも頼めます。

**✨ 種明かし**
「『実行前に計画を見せて』と言いましたよね。あれがCoworkと安全に付き合う合言葉です。計画を人間が確認してからGOを出す。この1クッションを挟むだけで、任せる怖さはほぼ消えます。今日の2つの実践は、皆さんの職場の"誰の仕事でもないけど誰かがやっている作業"を確実に減らします。」

### STEPごとの講師メモ

- **STEP1／導入でつまずかせない：** 拡張機能の追加権限がない会社PCの受講者には、隣の人とペアで進めてもらうか講師画面で追体験してもらう。英語ページの翻訳デモは反応が良いので1回入れると場が温まる。（確認：ページを1枚読ませて要約が返ってくればOK。）
- **STEP2／安全ルールは先に釘を刺す：** 「勝手にメールを送っちゃうのでは」という不安と「全部任せたい」という過信、両方が出るパート。デモボックスの3ルールを声に出して読み上げ、以降の実践でも都度リマインドする。（確認：4つのできることと安全ルール3つが言えればOK。）
- **STEP3／お題の統一も可：** 受講者が題材に迷う場合は「ノートPC3機種の比較」など全員共通のお題を出すと進行が揃う。④の検討メモまで到達させることを優先し、⑤の清書は時間次第で省略可。（確認：比較表→検討メモまで作れていればOK。）
- **STEP4／擬人化で通す：** 「チャット＝電話相談、Cowork＝席が隣の同僚」のたとえが通りやすい。フォルダ許可の画面で不安がる人には「許可した引き出ししか開けられない」と言い換える。（確認：ChatとCoworkの違いを一言で言え、フォルダ許可まで済んでいればOK。）
- **STEP5／練習用フォルダを配る：** 実践①用に、雑多なダミーファイル一式（zip）を事前配布しておくと全員同じ条件で進む。実データでやりたい人には必ずコピーを作らせてから。/scheduleとグローバル指示はデモだけ見せて「持ち帰りの宿題」にしてよい。（確認：整理タスクと初稿づくりの両方でCoworkの報告まで確認できたらOK。）
- **STEP6／宿題（任意）：** 「自宅・職場のフォルダを1つ、Coworkに整理させる」を宿題に。次回冒頭に「何分の作業が消えたか」を共有してもらうと、自動化の効果が実感として積み上がる。
