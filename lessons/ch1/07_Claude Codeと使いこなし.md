# Claude Codeと使いこなし

最終回です。前半は「Claude Code」——名前に"Code"と付いていますが、エンジニア専用ではない、Coworkの兄弟分にあたる本格的な働き手——にどこまで任せられるかを体験します。後半は7回の総仕上げとして、AIの限界との付き合い方を学びます。

---

## STEP1　Codeに任せてみる（🎬 体験する）

**ゴール：** Claude Codeに最初の仕事を任せてみる（目安25分）

**🎙️ 導入トーク**
「最終回です。今日の主役は『Claude Code』——名前に"Code"と付いていますが、エンジニア専用ではありません。前回までのCoworkの兄弟分で、より本格的な作業を任せられる働き手です。まず、難しい説明の前に1つ仕事を頼んでみましょう。」

1. Claude Desktop（またはターミナル）で Claude Code の画面（コードタブ）を開く
2. 画面の見方を確認する：下の入力欄に日本語で頼む → 上に作業の経過が流れる、それだけ
3. 練習用フォルダを対象に「このフォルダのファイル一覧を、種類と更新日つきの表にして」と頼む
4. 経過表示を眺める——Claudeが自分でコマンドを選び、実行し、結果をまとめる様子を観察する
5. 続けて「その表をCSVファイルとして保存して」と頼み、ファイルが実際にできたことを確認する

**✨ 種明かし**
「プログラムを書いたのはClaudeで、皆さんは日本語で頼んだだけ。これがClaude Codeです。『コードを書けるAI』ではなく『コードという道具を使って、あなたの作業を片付けるAI』と捉えてください。今日の前半はこの道具でどこまでできるか、後半は7回の総仕上げとして"AIの限界との付き合い方"を学びます。」

---

## STEP2　Codeとの使い分け（📖 学ぶ）

**ゴール：** CoworkとClaude Codeの使い分けを掴む（目安25分）

**🎙️ 導入トーク**
「前回のCoworkと今日のClaude Code、何が違うのか。結論から言うと、**迷ったらCoworkで十分**です。そのうえで、Codeが力を発揮する場面を知っておきましょう。」

|  | Cowork | Claude Code |
| --- | --- | --- |
| イメージ | 気の利く同僚 | 本格的な作業員（道具一式持ち） |
| 得意な仕事 | ファイル整理・資料づくり・日常の自動化 | 大量データの加工・分析・繰り返し処理・精密な変換 |
| 規模感 | 数十ファイル・日常業務サイズ | 数千行のデータ・数百ファイルでも安定 |
| 向く人 | 全員（まずはここから） | 定型の大量処理を持っている人 |

**💡 非エンジニアがCode に頼めること（今日の三種の神器）**
**① ファイル仕事：**整理・一括リネーム・CSV加工・PDF変換。**② データ分析：**数千行の売上データの集計・傾向分析・グラフ自動生成。**③ 文章生成：**データにもとづくレポート・定型文書の量産。——どれも「Excelが固まる」「手作業では日が暮れる」規模で真価が出ます。

**✨ 種明かし**
「使い分けの目安は**『量』**です。手作業でギリギリできる量ならCowork、『これは人間がやる量じゃない』と感じたらClaude Code。皆さんの職場の"月末の地獄の作業"を思い浮かべてください。あれが候補です。」

---

## STEP3　三種の神器 実践（✋ 実践する）

**ゴール：** 大量データの分析→グラフ→レポートを一気通貫でやる（目安45分）

**🎙️ 導入トーク**
「では三種の神器を通しで使います。お題は『1年分の売上データから、月次レポートを自動で作る』。配布した練習用CSV（またはご自身のデータのコピー）でやってみましょう。」

1. 練習用フォルダにCSVデータを置き、「このCSVの中身をまず要約して」と全体像を掴ませる
2. 「月別・カテゴリ別に集計して、傾向と気になる点を教えて」と分析を頼む
3. 「月別推移とカテゴリ構成比のグラフを画像で作って」と可視化する
4. 「ここまでの分析とグラフを使って、上司向けの月次レポートをWordで作って。構成はサマリー・好調点・懸念点・来月のアクション」と仕上げる
5. 時間が余ったら：「毎月同じ形式のCSVを置いたら、同じレポートを作れるように手順をメモして」と再利用の仕込みまで

**✨ 種明かし**
「データ読み込み→集計→グラフ→レポート。人がやれば丸1日の仕事です。そして⑤に注目してください——手順をメモさせれば、来月は『いつもの月次レポートを』の一言で済む。第6回のスキルの考え方と同じです。**1回できた仕事は、仕組みにして繰り返す**。これがAI活用の複利です。」

## STEP4　意図とズレる理由（📖 学ぶ）

**ゴール：** Claudeが意図とズレる仕組みを理解する（目安25分）

**🎙️ 導入トーク**
「ここからは総仕上げ、『AIの限界を知る』パートです。7回使ってきて、皆さんも経験したはずです——『なんか話が通じてないな』という瞬間。あれには理由があります。理由が分かれば、直せます。」

| ズレる原因 | 何が起きているか | 直し方 |
| --- | --- | --- |
| ① 指示の曖昧さ | 「いい感じに」をClaudeが別の意味で解釈 | 第2回の型（役割・背景・条件・形式）に戻る |
| ② 前提の欠落 | あなたの常識をClaudeは知らない | プロジェクト・メモリに前提を預ける（第3回） |
| ③ 会話が長すぎる | 下で説明する「コンテキスト圧縮」 | 話題が変わったら新しいチャットを開く |

**💡 コンテキスト圧縮——会話が長くなると何が起きるか**
第3回で「Claudeの作業机は広い」と学びました。それでも会話が延々と続くと机はいっぱいになり、Claudeは古いやり取りを**要約して畳む**ことで場所を空けます。これが「コンテキスト圧縮」。畳まれた部分の細部は失われるので、「さっき言ったのに忘れてる」が起きるのです。故障ではなく、机の整理の副作用です。

**✨ 種明かし**
「対策はシンプルです。**1チャット1話題**。仕事が変わったら新しいチャットを開く。長い作業では、途中で『ここまでの決定事項をまとめて』と自分で棚卸しさせて、大事なことを畳まれる前に固定する。この2つで、ズレの大半は防げます。」

## STEP5　ウソを見抜く（📖 学ぶ）

**ゴール：** ハルシネーションを見抜き、防ぎ、軌道修正できるようになる（目安30分）

**🎙️ 導入トーク**
「最後の関門、『ハルシネーション』です。AIが、事実でないことをもっともらしく言う現象。Claudeは他のAIより誠実に設計されていますが、ゼロではありません。見抜き方と防ぎ方を身につけて、この講座を締めましょう。」

|  | 内容 |
| --- | --- |
| 起きやすい場面 | 固有名詞の詳細（人名・製品仕様・法律の条文番号）／最新の出来事／細かい数値・統計／「知らない」と言いにくい流れの質問 |
| 危険なサイン | やけに具体的なのに出典がない／同じ質問を言い換えると答えが変わる／自信満々の断定口調 |
| 見抜き方 | 「その根拠は？」「出典を教えて」と聞く／Web検索スキルで裏取りさせる／重要な数字は原典に自分で当たる |

**💡 防ぐ・軌道修正する実践フレーズ**
**予防：**「分からない場合は推測せず『分からない』と言って」「事実と推測を分けて書いて」を依頼に添える。**軌道修正：**怪しい答えが出たら「本当に？根拠を確認して」と一度立ち止まらせる。訂正されたら「以後この点は推測しないで」と釘を刺す。**鉄則：**社外に出す数字・名前・引用は、必ず人間が原典確認。

**✨ 種明かし**
「思い出してください、第1回で『Claudeは誠実さを重視して設計されている』と学びました。だから『分からないなら分からないと言って』という一言が、Claudeには特によく効きます。AIを疑う技術は、AIを使い倒すための技術です。怖がるためではなく、安心して任せる範囲を広げるために、今日の見抜き方を使ってください。」

### STEPごとの講師メモ

- **STEP1／黒い画面アレルギー対策：** ターミナル画面に身構える人が必ずいる。「入力欄とチャットの位置が違うだけで、やることは今までと同じ」と最初に言い切る。デスクトップアプリのコードタブから入ると心理的ハードルが低い。（確認：日本語の依頼でファイル一覧→CSV保存までできればOK。）
- **STEP2／無理に使わせない：** 「全員がCodeを使いこなす」をゴールにしない。「Coworkで足りる人はそれでいい。ただし大量処理の選択肢があると知っていることが財産」というスタンスで。受講者の実務から"地獄の作業"を聞き出して次STEPの題材にする。（確認：「迷ったらCowork、量が多いならCode」が言えればOK。）
- **STEP3／練習用CSVを必ず用意：** 1年分×数百行の架空売上CSVを事前配布する（実データ持ち込みはコピーで）。途中でエラーが出ても「エラー文ごとClaudeに見せれば直る」を実演すると、トラブル対応力ごと持ち帰ってもらえる。（確認：分析→グラフ→レポートまで完走できていればOK。）
- **STEP4／受講者の失敗談を集める：** 冒頭で「Claudeと話が通じなかった経験」を挙手で集め、原因①②③のどれだったかをその場で仕分けすると、表が自分ごとになる。「故障ではなく仕組み」というフレーミングで安心させる。（確認：ズレの3原因と「1チャット1話題」が言えればOK。）
- **STEP5／実演で1回騙されてみせる：** 細かい固有名詞の質問でハルシネーションを誘発し、「根拠は？」で崩れる様子を見せると一発で伝わる（事前に再現する質問を仕込んでおく）。「AIのウソを見抜けた」という成功体験で終えるのがポイント。（確認：危険なサイン・見抜き方・予防フレーズが1つずつ言えればOK。）
- **STEP6／定着プランは書かせて持ち帰らせる：** 最後のワークは口頭でなく必ず書かせる（配布シートかスマホメモ）。可能なら1か月後のフォロー会や連絡先を案内して、講座を「点」で終わらせない。アンケートはこの場で回収する。
