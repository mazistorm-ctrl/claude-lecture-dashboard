「ChatGPTやGeminiを使ったことがある方も多いと思います。ではClaudeは何が違うのか。ざっくり言うと、Claudeは『長い文章を破綻なく理解する力』と『誠実さ』に強みがあります。ここを押さえると、どの仕事をClaudeに任せるべきかが見えてきます。」

💡 補足：Constitutional AI（憲法AI）

Claudeは「Constitutional AI」という設計思想で作られています。安全性と誠実さを重視し、知らないことは知らないと言い、無理に話を合わせません。だから業務で"信頼して任せられる"のが強みです。

✨ 種明かし

「使い分けのコツはこうです。最新情報の検索や画像生成は、ChatGPTやGeminiも便利。でも『自社の資料を読ませて考えさせる』『長い文章を扱う』『正確さが要る』——こういう仕事はClaudeが一枚上手です。この講座では、まさにその領域を伸ばしていきます。」

講師メモ：優劣ではなく役割の違い

「どれが一番か」ではなく「役割が違う」と伝えるとフラットに入る。受講者が普段使っているAIを聞いて、その延長線でClaudeの立ち位置を説明すると腹落ちしやすい。

✓

🎬体験する ゴール：実際にClaudeを開いて1往復する（目安20分）
🎙️ 導入トーク

「では実際に触ってみましょう。難しい設定はありません。ログインして、チャット欄に話しかけるだけです。『新しく入った優秀な同僚に仕事を頼む』——そんな感覚でやってみてください。」

  1. ブラウザで claude.ai を開く（またはデスクトップアプリを起動）してログインする
  2. 「新しいチャット」を開く
  3. 「自己紹介してください。あなたはどんな仕事が得意ですか？」と入力して送信する
  4. 返ってきた答えを一緒に読む
  5. 続けて「では、私の〇〇（あなたの職種・業務）で手伝えることを3つ提案して」と聞いてみる
やってみる：入力例

「私は小さな会社の総務担当です。日々の業務でClaudeに手伝ってもらえそうなことを、具体的に3つ提案してください。」
→ 議事録の要約、案内メールの下書き、備品リストの整理…といった提案が返ってきます。

✨ 種明かし

「これだけです。特別な操作は何もありません。次は、無料版と有料版の違い、そして3つのモデルの使い分けを押さえて、"迷わず使える"状態にしましょう。」

講師メモ：全員が1往復

ここで手が止まる人が出やすい。ログインまでは全員そろってから進める。返答が返ってきた瞬間の「おお」という反応を拾って場を温める。

✓

全員がチャットで1往復できていればOK。

📖学ぶ ゴール：プランとモデルの使い分けを掴む（目安20分）
🎙️ 導入トーク

「Claudeには無料版と有料版、そして3つのモデルがあります。ここだけ押さえれば、コストで迷うことはありません。料理に例えながら見ていきましょう。」

プランできること向いている人
無料版手軽に試せる。ただし利用量に上限・混雑時に制限・一部機能や上位モデルに制限まず触ってみたい人
有料版（Pro / Team）利用量が大幅増・上位モデル・プロジェクト／コネクタ／各種機能をフルに使える仕事で日常的に使う人
モデル特徴使いどころ速度
Haiku軽量・高速・低コスト定型文・簡単な返信・軽い整理⚡⚡⚡
Sonnet（推奨）バランス型・日常使いに最適文章作成・資料づくり・分析全般⚡⚡
Opus最高性能・複雑なタスク向け複雑な分析・長文・戦略立案⚡
✨ 種明かし

「迷ったらSonnet、と覚えてください。日常業務の9割はSonnetで足ります。軽い定型作業はHaiku、複雑な分析や長文・戦略は Opus。これだけで使い分けはOKです。なお、Claudeも万能ではありません——最新のリアルタイム情報や、正確な計算は苦手なことがあります（この見抜き方は第7回で扱います）。」

講師メモ：Sonnet一択で不安をなくす

モデル選択で固まる人が多い。「普段はSonnet」で断言してあげると安心する。コストの話は深掘りせず「定額の範囲で十分」程度に留める。

✓

「普段はSonnet」が言えればOK。

✋実践する ゴール：自分の仕事の1タスクをClaudeにやらせる（目安30分）
🎙️ 導入トーク

「ここが今日の本番です。皆さんの実際の仕事から1つ、Claudeに任せてみましょう。うまくいくコツは『具体的に・背景つきで』頼むこと。丸投げではなく、条件を添えるのがポイントです。」

  1. 今週やる予定の"文章仕事"を1つ選ぶ（メール返信・議事録の要約・案内文・企画のたたき台 など）
  2. 背景と目的を1〜2文で伝える
  3. 「〜を作って。読み手は〇〇、トーンは〇〇、長さは〇〇」と条件を添える
  4. 出てきた答えに「もっと〇〇して」と2〜3回、修正を重ねる
  5. 完成物をコピーして、そのまま使える形にする
プロンプト例（業種問わず使えます）

「来週の展示会の来場お礼メールを作ってください。宛先は名刺交換をした見込み客、トーンは丁寧だが硬すぎず、300字程度。最後に次回の商談につながる一言を添えてください。」

✨ 種明かし

「どうでしたか。ゼロから書くより圧倒的に速い。しかも『ここを直して』と言えばすぐ直る。これが毎日の仕事で効いてきます。次回は、これを文書・Excel・スライドといった"成果物づくり"に広げていきます。」

講師メモ：1人1成果を共有

各自ができた成果物を1つずつ発表してもらうと、他の人のユースケースが刺激になる。「こんな使い方もあるのか」の連鎖を作る。時間が押したら2〜3名でOK。

全員が自分の仕事の1タスクを完成させられていればOK。

✨ 種明かし

「今、会話とは別のウィンドウでファイルが組み上がっていくのが見えましたね。これは『アーティファクト』という機能です。Claudeが作った成果物を、会話と分けて管理してくれる——今日の主役です。数式もグラフも、中身ごと作ってくれたことに注目してください。」

講師メモ：最初の5分で驚きを作る

説明より先に「ファイルができた」という体験を全員に作る。プロンプトはコピペで構わない。ダウンロードして実際にExcelで開くところまでやると「本当に使える」実感が出る。

✓

📖学ぶ ゴール：伝わるプロンプトの「型」を身につける（目安25分）
🎙️ 導入トーク

「なぜさっきのプロンプトは一発でうまくいったのか。実は、伝わる頼み方には『型』があります。難しいテクニックではありません。新しく入った同僚に仕事を頼むとき、皆さんが自然にやっていることと同じです。」

要素何を伝えるか例
① 役割誰として答えてほしいか「あなたは経理の実務に詳しいアシスタントです」
② 背景・目的なぜ必要か・誰が使うか「新入社員向けの説明資料に使います」
③ 条件内容・分量・トーン「箇条書き中心・A4一枚・硬すぎない言葉で」
④ 形式どんな形で出すか「Excelで」「Wordで」「表形式で」
💡 Before → After で見る違い

Before：「請求書のテンプレ作って」
→ 悪くはないが、想定と違うものが出がち。
After：「小さな会社の営業事務として使う請求書テンプレをExcelで作ってください。品目・単価・数量・小計・消費税・合計を自動計算。取引先に送っても恥ずかしくないシンプルなデザインで。」
→ ほぼそのまま使えるものが一発で出る。

✨ 種明かし

「この『役割・背景・条件・形式』の4点セットが、いわゆる指示の構造化です。全部を毎回書く必要はありません。迷ったら『誰が・何のために・どんな形で』の3つだけでも、結果が大きく変わります。今日はこの型を全部の成果物づくりで使い回します。」

講師メモ：受講者の実業務で1回変換

1〜2名に「最近AIに頼んで微妙だった指示」を挙げてもらい、その場で4要素の型に直してみせる。自分の業務に引きつけた瞬間に定着する。

✓

「役割・背景・条件・形式」の4要素が言えればOK。

渡せるもの例頼めること
PDF契約書・マニュアル・報告書要約・重要ポイント抽出・Q&A

  4. 続けて「この内容について、新人に説明する想定で質問に答えて」と深掘りしてみる
✨ 種明かし

「『読ませてから頼む』——これが業務活用の基本形です。資料を渡す → 型に沿って条件を付ける → 成果物に変換する。この往復ができると、会議メモから議事録、データから報告書、と仕事が一気につながります。ちなみに、この成果物が並ぶ場所がさっきのアーティファクト。修正を頼むと同じ場所で更新されていくので、完成まで何度でも直せます。」

講師メモ：機密情報の扱いに一言

アップロード体験の前に「社外秘・個人情報は各社のルールに従う」と必ず一言添える。練習用には手元の公開資料や、このダッシュボードのスクリーンショットでも代用できる。

✋実践する ゴール：自分の業務で使うExcel・Word文書を実際に作る（目安35分）
🎙️ 導入トーク

「ここからが今日の本番です。皆さんの実際の業務で使うファイルを作ります。コツはさっきの型に『数式やグラフも入れて』と一言添えること。Claudeは見た目だけでなく、中身のロジックごと作ってくれます。」

  1. 自分の業務から「表で管理しているもの」を1つ選ぶ（案件リスト・勤怠・在庫・経費・顧客名簿 など）
  2. 型（役割・背景・条件・形式）に沿ってプロンプトを書き、Excelで生成する
  3. 「〇〇の列を足して」「集計を月別にして」と2〜3回修正を重ねて仕上げる
  4. 続けて、文書もの（案内文・手順書・お知らせ）を1つWordで生成する
  5. 「これをPDFでもください」と頼んで、配布用PDFまで作る
プロンプト例（業種問わず使えます）

Excel：「営業チームの案件管理表をExcelで作ってください。列は案件名・担当者・状況・金額・期日。状況別の件数を自動集計するエリアと、期日が近い順に見られる並びにしてください。」
Word：「経費精算ルール変更の社内案内をWordで作ってください。読み手は全社員、A4一枚、変更点は箇条書きで先頭に、質問窓口の案内を最後に。」

✨ 種明かし

ここで進度差が一番出る。早い人には「もう1ファイル」か隣のサポート役を頼む。遅れている人はデモボックスのコピペからでOK。完成の質より「修正を重ねて仕上げた」体験を優先する。

✋実践する ゴール：スライドを一発生成し、拡張思考で質を上げる（目安30分）
🎙️ 導入トーク

「最後の成果物はスライドです。そしてもうひとつ、Claudeに『じっくり考えてから答えてもらう』モードも体験します。まずはスライドから。説明したいテーマを1つ思い浮かべてください。」

  1. 説明したいテーマを1つ選ぶ（新ルールの説明・サービス紹介・月次報告 など）
  2. 「PowerPointで・5枚構成・読み手は〇〇」と型に沿って生成する
  3. できた構成を確認し、「3枚目をもっと具体的に」など修正する
  4. 入力欄の設定から拡張思考（Extended Thinking）をONにする
  5. 「このスライド構成を、読み手がもっと納得しやすい流れに再構成して。理由も添えて」と頼む
プロンプト例

「自社サービスの紹介スライドをPowerPointで作ってください。読み手は初めて話を聞く見込み客。構成は、表紙 → 相手の課題 → 解決策 → 実績 → 次のステップの5枚。1枚につき伝えることは1つに絞ってください。」

✨ 種明かし

「後半で使ったのが拡張思考（Extended Thinking）です。Claudeが答える前に、時間をかけて深く考えるモード。単純な作業には不要ですが、構成の練り直し・複雑な比較・計画づくりのような『考える仕事』ほど効きます。普段はOFF、ここぞという時にON、と覚えてください。」

講師メモ：待ち時間を活用

拡張思考は回答までに時間がかかる。待っている間に「皆さんの業務で"ここぞ"はどんな場面か」を問いかけて、使いどころのイメージを持たせる。

✓

スライドを1本生成し、拡張思考を1回試せていればOK。
